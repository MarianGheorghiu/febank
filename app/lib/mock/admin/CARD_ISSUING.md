# Card Issuing

Current implementation and Go integration contract: [Card Issuing workspace](../../card-issuing/README.md).

The issuing registry is shared with Cards Vault, Settings, User Management and Audit Logs. Changes to card lifecycle, limits and channels have application-wide impact. Issuance and servicing do not move wallet funds. The refreshed UI includes registry, fulfilment, cardholders, audit, portfolio charts and an indicative authorization sandbox.
